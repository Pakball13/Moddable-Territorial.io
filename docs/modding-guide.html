1. Introduction

1.1 What is Modatorial.io?

Modatorial.io is a client-side modding platform for territorial.io. It runs entirely in your browser, requires zero changes to the original game, and gives mods a stable, well-documented API.

At its core, Modatorial.io is a single JavaScript file (modLoader.js) that wraps four browser APIs the game uses:

  • WebSocket — to observe and optionally rewrite network traffic
  • requestAnimationFrame — to run code before/after each frame
  • CanvasRenderingContext2D — to hook into the draw loop
  • DOM events — keydown, mousedown, etc.

It then exposes a friendly window.TerritorialMods object and reads a set of mods from the mods/ folder (or from localStorage for store-installed mods).

1.2 What you'll learn

By the end of this guide you'll be able to:

  • Write a mod from scratch in under five minutes
  • Draw on the game canvas, hook into the update loop, and read internal state
  • Package your mod as a .ttmod file
  • Publish it to the community store
  • Debug and profile it like a pro

2. Setup

2.1 Requirements

DevToolsBuilt into every browser (F12)

2.2 Serving locally

Browsers refuse to fetch() from file:// URLs, so you need a local HTTP server. The simplest: 

cd path/to/moddatorial.io
python3 -m http.server 8000
# open http://localhost:8000/index.html

Alternatives:

  • npx serve . (Node)
  • VS Code's Live Server extension — right-click index.html → Open with Live Server
Heads up: after adding or deleting mods, do a hard reload (Ctrl+Shift+R). Some static servers cache JSON aggressively.

2.3 Opening the console

Every browser's DevTools has a Console tab. Open it with F12 or Ctrl+Shift+J (Cmd+Opt+J on Mac). This is where the loader logs everything, and where you'll paste one-off scripts.

Filter the console to only your mod's output:

// In the console:
TerritorialMods.debug = true;

3. Your First Mod

3.1 The 30-second mod

Create this folder tree inside your project:

mods/
└── hello-world/
    ├── mod.json
    └── main.js

mods/hello-world/mod.json

{
  "name": "Hello World",
  "version": "1.0.0",
  "author": "You",
  "description": "Shows a toast on load.",
  "main": "main.js"
}

mods/hello-world/main.js

api.showToast('Hello, world!');

3.2 The manifest

The loader reads mods/manifest.json to know which folders to scan. Add your mod's folder name to the array: 

{
  "mods": [
    "hello-world"
  ]
}

Order matters: mods are loaded top-to-bottom, but the dependency solver will reorder them if needed (see §8).

3.3 Reloading

Hard-reload the page. You should see:

[ModLoader] Loaded: Hello World (hello-world) v1.0.0
[ModLoader] Done. 1 mod(s). Click "Mods" or press F10.

And a toast should pop up at the bottom of the screen saying Hello, world!

If nothing happens, open the console and look for red text. The most common cause is a missing comma in the JSON — the console will tell you the exact line.

4.2 main.js

The loader wraps main.js in a function that receives two arguments: api and mod. 

(function (api, mod) {
  "use strict";

  // Your code here.
  // `api` is the shared window.TerritorialMods object.
  // `mod` is this mod's metadata (with .basePath and .config).

})(window.TerritorialMods, /* your meta */);

You can return an object at the end — that becomes mod.exports, readable by dependent mods.

4.3 icon.png

Optional. Square, ≥ 256×256, PNG or WebP. If omitted, the store uses a neutral placeholder.

4.4 Subfolders

Any file inside your mod folder is accessible via api.readModFile(mod, path). Paths are relative to your mod root and use forward slashes on every OS. 

const sound = await api.readModFile(mod, 'assets/ding.ogg', 'blob');

5. The API

5.1 Lifecycle

api.version            // "2.0.0"
api.gameVersion        // 25
api.mods               // Map<id, meta>
api.self               // this mod's meta

5.2 Events

A tiny publish/subscribe system.

const off = api.on('event-name', handler);
off();                             // unsubscribe
api.off('event-name', handler);    // same
api.emit('event-name', 1, 2, 3);   // fire custom

Built-in events: modLoaded, modsLoaded, ready, plus raw DOM events forwarded verbatim.

5.3 Hooks

Hooks are called by the game. Register with api.addHook(name, fn). See Appendix B for the full list. 

api.addHook('preRender', ctx => {
  ctx.fillStyle = 'red';
  ctx.fillRect(0, 0, 20, 20);
});

5.4 UI helpers

api.showToast('msg', 3000);
const btn = api.addButton('⚔ Attack', () => doAttack());
api.addStyle('.my-thing { color: red; }');
const el = api.createElement('div', { class: 'x' }, 'Hello');
api.mountChrome({ id: 'my-widget', render: () => node });

5.5 Game access

api.getGameCanvas()    // <canvas id="canvasA">
api.getGameContext()   // its 2D context
api.getGameSize()      // { width, height }
api.isInLobby()        // boolean
api.isInGame()         // boolean
api.getPlayerName()    // string
api.getPlayerColor()   // "#rrggbb"
api.getPlayerIndex()   // number
api.getPlayerCount()   // number
api.getHumanCount()    // number
api.getLeaderboard()   // [{ name, color, territory, rank }]

5.6 File access

const txt  = await api.readModFile(mod, 'notes.txt');
const json = await api.readModFile(mod, 'config.json', 'json');
const img  = await api.readModFile(mod, 'icon.png',    'image');
const blob = await api.readModFile(mod, 'sound.ogg',   'blob');

6. Deep Internals

6.1 window.__TT__

For advanced mods, the loader exposes a read-mostly view of the game's own closure variables: 

const TT = api.getGame();
// TT.ah  — per-player arrays (names, colors, scores)
// TT.aE  — game state ({ data, fJ, fW, ku, a2G })
// TT.ad  — map / territory data
// TT.aj  — name generator (has .a8() method)
// TT.bm  — buffer / settings
// TT.ac  — image cache
// TT.b1  — network manager
// TT.bD  — UI utilities
// TT.aT  — ranking

6.2 Player arrays

PathMeaning
ah.a0j[i]Player i's display name
ah.a2w[i]Player i's name (secondary, tag)
ah.nU[i]Is player i alive (1) or empty (0)?
ah.a5a[i]Player i's status (0=human, 2=bot)
ah.a2Z[i]Player i's kill count
aE.fJLocal player's index
aE.kuHow many players are human
aE.fWTotal player slots

6.3 Map data

TT.ad holds the territory grid. It's a flat Uint16Array of owner indices. The map is ad.j wide by ad.k tall. 

const { ad } = api.getGame();
const w = ad.j, h = ad.k;
const ownerAt = (x, y) => ad.a3V[y * w + x];
Stability: these internals are undocumented and may change without warning when territorial.io updates. Wrap access in try/catch and guard with feature detection.

7. Common Recipes

7.1 Live HUD

let fps = 0, frames = 0, last = performance.now();

api.addHook('postUpdate', () => {
  frames++;
  const now = performance.now();
  if (now - last >= 1000) { fps = frames; frames = 0; last = now; }
});

api.addHook('preRender', ctx => {
  ctx.save();
  ctx.font = 'bold 16px system-ui';
  ctx.fillStyle = 'rgba(0,0,0,0.6)';
  ctx.fillRect(8, 8, 90, 28);
  ctx.fillStyle = '#3fb950';
  ctx.fillText(`${fps} FPS`, 16, 28);
  ctx.restore();
});

7.2 Bot renamer

const NAMES = ['bob', 'john', 'ur mom', 'zack', 'bobir'];

function tryPatch() {
  const TT = window.__TT__;
  if (!TT || !TT.aj || TT.aj.__patched) return !!TT?.aj?.__patched;

  const orig = TT.aj.a8.bind(TT.aj);
  TT.aj.a8 = function () {
    orig();
    const { ah, aE } = TT;
    if (!ah || !aE) return;
    for (let i = aE.ku; i < aE.fW; i++) {
      if (ah.nU[i] === 0) continue;
      const n = NAMES[i % NAMES.length];
      ah.a0j[i] = n; ah.a2w[i] = n;
    }
  };
  TT.aj.__patched = true;
  return true;
}

if (!tryPatch()) {
  const iv = setInterval(() => { if (tryPatch()) clearInterval(iv); }, 100);
}

7.3 Key bindings

api.addHook('keyDown', e => {
  if (e.target.tagName === 'INPUT') return;  // don't hijack typing
  if (e.code === 'KeyG') { api.showToast('GG!'); }
});

7.5 Network sniffer

api.addHook('netSend', (data, ws, url) => {
  console.debug('[sniff] →', data.byteLength ?? data.length, 'bytes to', url);
});

  console.debug('[sniff] ←', data.byteLength ?? data.length, 'bytes from', url);
});

8. Packaging & Publishing

8.1 The .ttmod format

A single-file, text-based, human-readable bundle:

<ttmod>
{ "name": "My Mod", "version": "1.0.0", "author": "You" }
</ttmod>
<script>
api.showToast('hi');
</script>
<assets>
{"icon.png": "data:image/png;base64,..."}
</assets>

8.2 Uploading to the store

await ModStore.publish({
  name:        'My Mod',
  author:      'You',
  description: 'Does something cool.',
  version:     '1.0.0',
  icon:        null,
  ttmod:       ttmodText,
  tags:        ['hud']
});

Uploads are rate-limited to 10 per hour per browser fingerprint.

8.3 Versioning

Always bump version when you publish. The store deduplicates by name + author and keeps the highest version. Old versions remain queryable in Firestore for rollback.

9. Debugging

9.1 Debug mode

TerritorialMods.debug = true;

Verbose logs every hook and event dispatch.

9.2 Reading stack traces

Each mod's script is loaded with a //# sourceURL= comment, so DevTools shows the mod's real path in stack traces. Example: 

Uncaught TypeError: ctx.filTtext is not a function
    at mods/kill-counter/main.js:14

9.3 Common errors

SymptomLikely cause
Mod card shows in menu but nothing runsMissing from manifest.json or a JS syntax error
404 on mod.jsonFolder name mismatch, or server needs restart
Cannot read property 'x' of undefinedYou accessed api.getGame() before the game finished loading
Hook fires zero timesThe hook doesn't run in the current game state (e.g. preRender on the menu)
Style doesn't applyCSS variables overridden later — add !important or use a higher-specificity selector

10. Best Practices

10.1 Cleanup

Any timer or listener you create should be torn down when the mod is unloaded. The loader auto-cleans hooks and api.on subscriptions, but setInterval and raw addEventListener are your responsibility: 

const iv = setInterval(tick, 1000);
api.on('unload', () => clearInterval(iv));

10.2 Namespacing

Prefix CSS classes and localStorage keys with your mod ID: 

api.addStyle('.killcounter-panel { ... }');
localStorage.setItem('tt-mod:kill-counter:best', '12');

10.3 Performance

  • Don't do heavy work in preUpdate/postUpdate — they run at 60 Hz. Throttle to every Nth frame if needed.
  • Cache api.getGame() results; don't call it every frame.
  • Batch canvas state: ctx.save() / ctx.restore() around every draw block.

10.4 Accessibility

  • Respect prefers-reduced-motion.
  • Don't hijack keyboard input when the target is an <input>.
  • Use semantic HTML in mod UI panels.
